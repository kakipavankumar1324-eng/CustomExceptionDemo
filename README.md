# CustomExceptionDemo

A simple Java program that demonstrates how to create, throw, and handle a **custom checked exception** in Java.

---

## 🚀 How It Works

This project contains a demonstration of custom exception handling using an age verification scenario:
* **`InvalidAgeException`**: A custom exception class that extends `Exception` (making it a checked exception).
* **Age Validation**: The program prompts or checks a user's age. If the age is **under 18**, it explicitly throws the `InvalidAgeException`.
* **Exception Handling**: The thrown exception is caught in a `try-catch` block, displaying a user-friendly error message instead of crashing.
